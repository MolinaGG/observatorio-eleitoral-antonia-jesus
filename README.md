# Observatório Eleitoral · Antônia de Jesus

Demonstração pública de resultados agregados da eleição de 2026 em São Paulo.

A interface em `dist/index.html` mostra indicadores preliminares publicados por veículos que reproduzem a apuração do TSE. A importação direta dos CSVs oficiais, o benchmark completo, os filtros por zona/seção e a geração pelo Ollama permanecem pendentes; a interface identifica essas limitações. O esquema de dados para o Neon está em `schema.sql`.

Fontes: https://dadosabertos.tse.jus.br/dataset/resultados-2026 · https://dadosabertos.tse.jus.br/dataset/candidatos-2026 · https://www.cnnbrasil.com.br/eleicoes/2026/candidatos/sp/deputado-estadual/pl/antonia-de-jesus/22456/

Voto é secreto: resultados por seção não identificam eleitores. A candidatura a vice-prefeita em 2024 está separada da votação nominal de 2026.
